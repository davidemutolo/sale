# sale.uspallacanestro.it

Disponibilità della sala piccola e della sala grande del Centro Sportivo Tazio Nuvolari (Savignano sul Panaro) nei weekend.

- `index.html`: la pagina
- `dati.json`: date occupate (aggiornate in automatico dal pannello prenotazioni). Contiene solo date, mai nomi.
- `CNAME`: dominio personalizzato per GitHub Pages
